# 🚚 STS Logistics Booking Frontend

## 📌 Overview
This is a frontend web application for a logistics and trailer booking system. It allows users to estimate fares, book transport services, and manage bookings.

## ✨ Features
- Instant fare estimation
- User login & signup UI
- Booking system with confirmation
- Dashboard for managing bookings
- Track booking functionality
- Responsive design (mobile-friendly)

## 🛠 Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
